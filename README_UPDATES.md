# Latest updates

- All article titles, excerpts, body copy, author bios and article-detail copy are lorem ipsum demo content while preserving category/post slugs for routing.
- Category URLs are canonicalized to `/<category>` (for example `/business`).
- Detail URLs are canonicalized to `/<category>/<post-slug>` (for example `/entertainment/casting-surprises-of-the-season`).
- Legacy `/category/<slug>` URLs redirect to `/<slug>`.
- Legacy `/post/<slug>` URLs redirect to `/<category>/<slug>`.
- Social icons use Twitter/X, YouTube, Instagram, Stack and Medium in the header, footer, side menu and article share/follow areas.
